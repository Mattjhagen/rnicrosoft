# rnicrosoft.com Security Training Simulation

A clearly labeled phishing-awareness training site for teaching users how to spot lookalike domains and suspicious sign-in prompts.

This is not a Microsoft clone. It does not include Microsoft branding, credential collection, tracking pixels, or working sign-in flows. The page is designed for safe internal awareness training.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.
